# FixMate Design Package v0.2

Refined visual direction and asset drafts based on the selected Smart Home + Shield concept and supplied reference board.

## Contents
- `assets/logos/`: clean SVG logo variants.
- `assets/banners/`: static SVG banners with no embedded buttons or functional-looking controls.
- `assets/icons/`: device and trust icon set.
- `assets/boards/`: visual reference board.
- `styles/`: light/dark CSS tokens.
- `docs/`: six design documents.

## Important
The logo is a simplified vector draft; review at favicon and small-header sizes before production approval. Typeface and colors are working choices pending accessibility verification. Board images are references, not production UI screens. This package contains design assets and documentation only, not application code.
